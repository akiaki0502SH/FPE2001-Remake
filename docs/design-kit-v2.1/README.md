# FPE2001-Remake UI Design Kit v2.1 / 实施状态 v3.0

本设计包以原版 FPE2001 的九个模块和原始顺序为信息架构基线，在不改变核心任务路径的前提下进行 Win11 化。v3.0 已将该设计稿落地到 WPF 表现层；ViewModel、Command、扫描引擎、地址表、文件编辑和适配器逻辑保持不变。

## 核心原则

- 顶部保留九模块顺序：内存搜索、地址表、编辑器、文件、图片、宏按键、速度、其他、关于。
- 模块下方保留 F1–F6 操作提示，快捷键与按钮使用同一命令。
- 编辑器同时支持文件、进程内存、快照；文件模式支持插入/删除/覆盖与原子保存，进程模式仅允许等长覆盖。
- 文件模块支持驱动器/目录导航、过滤、递归内容扫描、取消和“在编辑器打开”。
- 所有地址、范围和文件偏移均按 64 位无符号值设计。
- 模块导航固定为 66 DIP，两行显示图标与名称；隐藏内部开发标记，避免名称被动作栏遮挡。
- 窗口层级固定为标题栏 44 DIP、模块导航 66 DIP、动作栏 44 DIP、工作区、状态栏 31 DIP。
- 页面统一使用灰青低饱和主题、1 DIP 边界、9 DIP 卡片圆角和轻量 DWM/卡片阴影。

## 文件

- `index.html`：可交互设计稿，单文件离线打开。
- `screens/`：1600×1000 静态页面稿。
- `design-tokens.json`：颜色、尺寸与字体令牌。
- `screen-map.json`：页面、原控件组与实现范围映射。
- `../specifications/FPE2001-Remake_UIUX实施规格_v3.0.docx`：UI/UX 实施规范与逐页基准图。
